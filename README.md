# Gundamaiah Annamaina — Static Portfolio

A responsive, accessible static portfolio made with plain HTML, CSS, and JavaScript. No framework, package install, build step, or server-side code is required.

## Files
- `index.html` — portfolio content and metadata
- `styles.css` — responsive design and visual styling
- `script.js` — mobile navigation and current year
- `assets/favicon.svg` — browser tab icon

## Preview locally
Open `index.html` in a browser. For a more realistic local preview, use VS Code Live Server.

## Publish to GitHub Pages
1. Back up your existing GitHub Pages repository first.
2. Extract this ZIP.
3. Copy the contents of this folder (not the containing folder itself) into the root of the repository.
4. Commit and push to the branch configured for GitHub Pages.
5. Wait for GitHub Pages to finish deploying, then open `https://gundamaiah.com`.

Keep your existing custom-domain configuration safe. If your repository has a `CNAME` file, preserve it with the single line:
`gundamaiah.com`
Do not delete or change DNS records if the domain already points correctly.

## Before publishing
- Verify the email and LinkedIn links.
- Check the career dates and titles.
- Consider adding a downloadable PDF resume and GitHub project links when ready.
- Confirm your employer's confidentiality rules before publishing any details about internal work. This portfolio describes outcomes at a high level and intentionally avoids source code, internal architecture diagrams, and confidential data.
